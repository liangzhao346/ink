## 罗盘工具栏（Vue 3 + Vite）

从零搭建 `ink` 项目，实现四层径向罗盘工具栏。

技术选型：Vite 6 + Vue 3.5（script setup，无 UI 库、无状态库）。

关键设计：
- 内部固定 600×600 设计坐标系，圆心 (300,300)，用 ResizeObserver 计算 scale 做自适应。
- 环带轨道用 SVG `<circle>` 绘制（r = 槽位中心半径，stroke-width = 环厚），
  `transform-box: view-box` + `transform-origin: 300px 300px` 实现缩放动画。
- 半径布局：核心 r56；L2 厚 76 槽位 r94；L3 厚 68 槽位 r166；L4 厚 64 槽位 r232。
- 槽位定位用 `rotate(θ) translateY(-r) rotate(-θ)`，θ = i/capacity*360，从 12 点顺时针。

核心改动：`src/composables/useRadialLayer.js`
- 固定槽位（按最大容量均分圆周），切换工具时内容**瞬时替换**，动画只发生在数量差的那一段。
- 变多：从 index = 旧数量 开始冒泡；变少：从 index = 旧数量-1 倒序破碎。
- 槽位状态机 hidden / entering / stable / exiting；只有 stable 可点击。
- `token` 自增 + 组件 `:key` 强制重建 DOM 以重启动画（连续快速切换工具时必需）。
- 层间错峰：展开时 L3 先（L4 +150ms），收起时 L4 先（L3 +150ms）。

数据：`src/data/tools.js` 工具池（鼠标/笔/橡皮擦/选择/形状/文本），
每个工具 `layers: [[第三层],[第四层]]`，数组长度决定该层是否显示与显示几个。
kind 决定按钮呈现：color / thickness / size / glyph / icon。

第二层 5 位 = 最多 4 个工具 + 固定设置位，设置面板可增删工具。

## v2：TS 化 + 模块化（新任务空间 `/Users/joyce/workbuddy-ai/program/ink-v2`）

v1（`/program/ink`）保持不动可对照。v2 端口 5273，v1 端口 5173。

架构约定（用户明确要求，后续沿用）：
- 全量 TypeScript：`vue-tsc --noEmit` 纳入 build 前置，`strict` + `noUnusedLocals` +
  `noUnusedParameters` + `verbatimModuleSyntax`（类型导入必须写 `import type`）+ `@/*` 别名。
- 目录：`src/types`（全量类型）/ `src/config`（静态配置，唯一真相来源）/
  `src/stores` / `src/modules/<feature>`（按领域分模块）/ `src/components`（通用 UI）。
- 罗盘模块 `src/modules/compass/`：Compass（组合四层）+ CompassRing（单层）+
  CompassButton（独立按钮组件）+ CompassCore + composables/（useRadialLayer /
  useSlotLayout / useCompassScale），并有 index.ts 桶文件。
- 按钮实例数由静态配置驱动：CompassRing 的 `slots` 长度 = `ring.capacity`，
  有内容就实例化一个 CompassButton，没内容退化为刻度点。

TS 关键手法：
- `LayerItem` 做成可辨识联合（color/thickness/size/glyph/icon/action），
  vue-tsc 能在模板 `v-if="item.kind === 'color'"` 里正确窄化，已验证通过。
- `ICONS` 用 `as const` → `export type IconName = keyof typeof ICONS`，新增图标自动获得约束。
- 环半径不再硬编码：只声明 thickness/capacity/buttonSize，半径由厚度从 CORE_RADIUS 累加推导
  (`buildRings`)，保证三层圆环严格紧密相连。
- `useRadialLayer` 返回带 `readonly` 字段的 `RadialLayer` 接口。

踩坑：`noUnusedLocals` 下 import 的类型没用到也会报错（如 useRadialLayer 的 SlotState）。
